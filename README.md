# HoneyDrunk Studios GitHub Defaults

This repository provides organization-level GitHub defaults for HoneyDrunk Studios.

## What GitHub uses from here

- `profile/README.md` renders on the HoneyDrunkStudios organization profile page.
- `.github/pull_request_template.md` is the default PR template for organization repositories that do not define their own PR template.

Repository-local files always win. If a repo has its own `.github/pull_request_template.md`, GitHub uses that instead of this default.
